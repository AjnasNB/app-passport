# Indian number learning reference
1 lakh = 100000. 1 crore = 10000000. 1 rupee = 100 paise. The Indian grouping system keeps the last three digits together, then groups pairs. 1234567 is written 12,34,567. This is a project-authored arithmetic fixture for teaching, not tax, investment or banking advice. All calculations use nonnegative amounts with at most two decimal places.
